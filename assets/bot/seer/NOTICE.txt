Adaptation for this game: PyTorch-to-ONNX actor-only export, explicit recurrent state,
TypeScript observations and action decoding, RocketSim-to-RLBot coordinate and
boost-timer conversion, and browser worker inference. Original trained weights,
feature scaling, action masks and deterministic categorical decisions are preserved.
Seer v0 is the public historical 1v1 model, not a later tournament Seer.
Competitive rank has not been measured in this game.

Reproduce: python tools/export-seer.py
Independent observation/sequence fixtures: python tools/verify-seer.py
